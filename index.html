Algorithm overview

Tips

If your data contains article information(e.g. name) of each transaction, then you can try Association rule.

If your data contains sales quantity(or price) and also some variables that change over time, try Prediction.

If your data contains sales quantity(or price) of each article(or of each store), you can do Clustering and Classification on article(or store).

Association rule

Algorithms: Apriori, FP-Growth.

Data preprocessing: Convert the data format to the following style:

0 1 2 ...
transaction1 article1 article2 article3 ...
transaction2 article4 article5 None ...
... ... ... ... ...

Experiment: Example Python libraries are efficient_apriori, pyfpgrowth, MLxtend.

Note: Libraries may require different data preprocessing, depend on the specific requirements.

Results: [{Broetchen} -> {Bananen Lose}, {Gurken ST} -> {Bananen Lose}, {Bananen Lose} -> {Gurken ST}...] [{Bananen Lose, Broetchen} -> {BO-Laugenbreze 1ST}, {BO-Laugenbreze 1ST, Broetchen} -> {Bananen Lose}...]

Insights: Different number of top-frequency articles will outcome different rule results. When few intereting results are produced, modify it!

Clustering

Experiment: Example Python library is tslearn.

Insights: The number of different top articles slightly affects the clustering results. For example in the above results, from selecting the top 20 articles to the top 10 articles, store number 1007 is clustered in the second cluster, while the other stores in the first cluster remain unchanged. This suggests that the other stores in the first cluster are concentrating their sales on the top 10 articles rather than others, and the shop manager can apply the same or similar promotions specifically on top 10 articles to those stable stores, while the fluctuating stores are analysed in more detail and promotions are applied individually.

Classification

Algorithms: Logistic regression, RandomForest classifier, Neural network.

Data preprocessing: Set sales quantity of each top articles as learning objects; store number as the objects to be classified.

Experiment: Example Python libraries are keras, tensorflow. Example software is Weka.

Note: Libraries may require different data preprocessing, depend on the specific requirements.

Results: RandomForest Classification accuracy: 78.5377% RandomForest Classification accuracy: 53.5377%

Insights: It is obvious that the more top-frequency articles lead to more accurate store classification results. However, analysing too many articles is impractical and boring, while the significance of a small number of articles with low accuracy is also very limited for store manager, so choosing the appropriate number of top articles to focus on is worth discussing.
